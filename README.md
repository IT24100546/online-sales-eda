# 🛒 Online Sales Data — Exploratory Data Analysis

## 📌 Overview
An end-to-end EDA project exploring 239 online sales transactions across 6 product categories, 3 regions, and 8 months of 2024.

## 🔍 Key Questions Explored
- Which product category generates the most revenue?
- How does revenue trend month by month?
- Which region performs best in sales and units?
- What payment methods do customers prefer?
- Which products are the top revenue drivers?

## 🛠️ Tools Used
- Python
- pandas
- matplotlib
- seaborn
- Google Colab

## 📊 Key Insights
- Electronics is the top revenue category, driven by high unit prices
- North America leads in revenue; Asia leads in units sold
- Credit Card is the dominant payment method
- Premium products like MacBook Pro drive disproportionate revenue

## 📁 Files
| File | Description |
|------|-------------|
| `Online_Sales_EDA.ipynb` | Main analysis notebook |
| `Online_Sales_Data.csv` | Dataset used |

## 🚀 How to Run
1. Clone or download this repository
2. Open `Online_Sales_EDA.ipynb` in Google Colab or Jupyter Notebook
3. Upload `Online_Sales_Data.csv` to the same environment
4. Run all cells from top to bottom
